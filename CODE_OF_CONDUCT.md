# Community conduct

Be respectful, constructive and specific. Harassment, discriminatory abuse, doxxing and deliberate exposure of private information are not acceptable. Discuss technical choices without personal attacks, and disclose conflicts relevant to a contribution.

Maintainer KasterMist may edit/remove abusive public content or restrict participation using GitHub moderation tools. To report a public conduct problem, reference the public interaction in a non-sensitive Issue. Do not publish private information; a private reporting channel is not yet configured and must be arranged before sharing sensitive details.

This is a project-specific conduct policy, not a claim of adopting an external code of conduct verbatim.
