## T27.1 的实际结果

`packages/core/src/wiki.ts` 新增独立、编辑器无关的预备 schemaVersion 2 模型。文章有分类、语言、修订、父子和顺序、章节及块。事实块只引用共享卡片的 ID/修订/规范内容哈希；说明块明确标注上下文、推测或人工设计理由。卡片继续是事实与源码证据的规范来源。

解析器检查目录循环、孤立父项、重复 ID/锚点/顺序、深度、内容长度及 UTF-8 总字节预算。引用的卡片变更、同修订正文被手改或卡片缺失时标记需要复核，并不悄悄替换成新版正文。引用匹配只表示卡片绑定一致，源码状态明确为 unchecked；它不能证明历史设计理由真实。

迁移/回退函数只生成确定性预览和哈希，不写文件、不自动备份、不启用新格式。升级仅把既有规范 v1 转为保留卡片的空文章 v2；遇到会 trim 现有正文等内容的输入则拒绝。回退拒绝丢弃非空文章。文章说明正文保留空白，原始 Markdown 字符串不执行。

当前实际 KnowledgeStore、MCP、生成、候选及发布器仍严格 v1；v2 输入会被拒绝。现有用户数据不迁移，也没有新增界面、模型调用或发布资产。完整未来激活门禁、旧记录处理和备份恢复契约见 [ADR 0015](../architecture/adr/0015-wiki-articles.md)。标注 human/model 只是数据，生成适配器以后必须自行确定作者身份，不能信任模型填写的 human。

## T27.2 阅读器切片

新增 Open Wiki Preview 和主页入口，选择显式的 schemaVersion 2 文章预览 JSON；随包 `demo/wiki-preview.json` 是自编两文章示例。文件只读、UTF-8 严格解码、限制 1 MiB；不搜索相邻目录，不导入数据，不激活 canonical v2。仓库 ID/来源修订必须匹配所选正式知识，预览中的卡片正文不替代当前正式卡片。

目录和文章在 Webview 中显示。事实块依照当前正式卡片解析引用；改动/缺失不替换正文。匹配引用通过现有 KnowledgeStore.read 核验源码，多次读取要求同一知识快照；源码状态区分 current/stale/unavailable/unchecked。源码导航仅接受当前文章已列出的 cardId/index/快照，不接受正文路径或命令；沿用根目录、符号链接、行范围和版本重检。改变配置/工作区关闭旧视图。

Markdown 使用锁定的 Marked 18.1.1 lexer，再由标签白名单渲染标题/段落/强调/代码/列表/引用/表格；不是直接信任 Marked HTML。所有文本转义，不执行 HTML，不输出正文链接、图片 URL 或资源属性。独立 lexer、深度/数量/输出预算、nonce/CSP、禁止 command URI/本地资源进一步约束视图。参考 [Marked 文档](https://marked.js.org/using_advanced)；实现以已锁定包的类型/代码及对抗性测试为准。该版本原为工程间接依赖，现声明为直接依赖，保留锁定 integrity 并随包列出 MIT 通知。

## T27.3 有界文章与关联卡片候选

统一生成表单新增 Wiki 文章＋关联卡片模式；模式也是预览绑定的一部分，切换后必须重新预览。显式确认发送已列出源码后，沿用受限 Codex 纯文本生成通道：一次任务、60 秒、64 KiB 输出，最多 3 篇概述/架构/模块文章及 2/4/8 张新卡片。打开/扫描/找回/阅读不启动模型。没有更改模型版本白名单、登录、代理、提供方或安全策略。

文章事实必须引用同批卡片，每篇至少一个事实块，每张卡片必须被文章使用。插件自行生成修订、语言、证据指纹及引用绑定；额外说明仅为模型推测，拒绝伪造 human/rationale 和设计理由卡片。校验越界证据/范围、重复/既有 ID、孤立/循环目录、未知字段、输出和层次预算；结构有效不代表语义正确。

新格式只用于外部 `wiki-candidates/<UUID>.json` 不可变暂存：保存元数据规划和有界输出，不保存完整源码包，不写正式知识、v1 卡片候选或历史。临时文件同步、重新核对源码/基线后通过同目录独占 hard link 暴露完整文件，不覆盖既有候选；不支持 hard link 时失败。失败不自动重试，也不宣称未完成模型任务可续跑。已完整保存的候选可以无模型重复找回；未保存时须重新预览并明确开始新任务。兼容/备份/中断文件处理见 [ADR 0016](../architecture/adr/0016-wiki-generation-staging.md)。

生成成功后面板可直接打开候选目录和 Markdown 阅读器。独立候选读者明确区分未发布卡片与正式事实，重新核验源码/基线变化；候选证据路径/行号先显示为不可点击文字，不进入正式知识的导航桥接。不能独立发布关联卡片，也不让旧读取器用候选正文替换正式卡片。[操作指南](../user/wiki-generation.zh-CN.md)。

自编自动化覆盖伪造作者/理由、缺失/未引用卡片、目录/证据/范围/输出限制、取消、未知后端、篡改身份和符号链接、原知识字节不变、重复找回及源码/正式知识变化后的过期显示；测试不请求真实模型。打包宿主另覆盖当前仓库与双根第二仓库的 Wiki 模式预览、完成态候选目录/阅读和规范知识不变。最终完整检查、精确 head 五项 CI 及合并证据集中在 Issue #58；这不冒充真实 Wiki 模型生成、视觉或新的 Remote SSH 验收。
