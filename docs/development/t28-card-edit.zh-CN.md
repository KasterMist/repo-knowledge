# T28：卡片正文编辑功能切片

按维护者要求，功能优先，视觉美化及侧栏管理区调整暂缓。

卡片右键或命令 Edit Card Body 打开正文/修改理由表单；宿主固定所选仓库、原卡片和快照。客户端不能指定 ID、修订、路径或证据。通过现有 propose 校验保存一份待审阅候选，不覆盖正式知识，不调用模型。后续使用 Review Proposal Diff / Publish Reviewed Proposal 单独审阅和确认发布。

输入长度有界，正文与仓库文本转义，nonce CSP、禁用资源/命令 URI。实际文件的未保存修改会拒绝提交；只读虚拟知识文档不应误拦截。工作区/配置变化关闭表单，成功后禁止重复提交。

边界：表单尚无自动草稿持久化；关闭前未提交内容不保存。卡片标题/证据编辑、文章说明编辑、图形冲突处理、图形增量更新以及真实 Remote SSH 验收仍待后续切片。卡片修订后文章旧绑定会按既有规则显示需复核，不自动重绑。

验证：143 单测、7 集成、实际 VSIX 完整检查通过；Windows VS Code 1.117.0 隔离宿主验证无效输入拒绝、保存候选、重复提交拒绝及原快照字节不变。早期宿主发现虚拟文档误拦截，修正后已通过。精确 head 五项 CI/合并记录见关联 PR。不发布版本、不改用户配置。
