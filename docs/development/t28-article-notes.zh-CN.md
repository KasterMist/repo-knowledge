# T28：人工文章说明编辑内核

2026-11-26 候选持久化增量：WikiNoteCandidates 核心 API 可显式保存、列出及读取独立不可变说明候选，保留完整编辑基线，重新实例化后可恢复；绑定已解析仓库/存储身份。正式知识变化时仍可读取旧差异，但 state=changed，旧请求不能重新保存。候选不发布、不修改正式快照。格式、容量/并发限制、失败残留和降级规则见 [ADR 0019](../architecture/adr/0019-human-note-staging.md)。下方“仅纯函数、无磁盘候选”是此前切片历史；当前仍无发布/回退事务或图形入口。

2026-11-26。当前仅提供纯函数 prepareWikiNoteEdit，不提供磁盘候选写入、发布器、历史格式或编辑界面，不应宣称用户已经可以编辑发布文章说明。

输入为已解析的 v2 正式快照、完整快照内容指纹、文章修订号、已有 section/block 标识、正文及修改理由。只允许修改已有 human note 的 body；保留说明分类、作者、引用、其他文章、所有卡片及其证据。文章修订递增，旧快照/旧修订拒绝，无变化拒绝，卡片事实块和模型说明拒绝，未知字段拒绝。返回前后快照及待审阅状态，不写文件、不调用模型，也不把内容指纹一致视为源码或历史理由已核验。

此切片没有新持久格式，无迁移行为。后续必须单独定义不可变说明候选、存储身份绑定和容量限制；新增发布历史操作须有 ADR、同锁/原子替换、中断恢复、原说明保留及单调修订回退，再接入图形审阅/独立确认。不得复用 create-wiki/remove-wiki 的新增/删除批次语义伪装正文编辑；旧读写器应明确拒绝未知历史版本。

测试覆盖：旧基线/修订拒绝、伪造作者字段、空白/无变化正文、事实块或模型说明拒绝、输入不变，以及卡片/共享引用不变。完整检查结果以对应 PR 与本轮状态记录为准。实际 GUI/Remote SSH 验收尚未发生。
