## 本轮改变

核心显式兼容模式 `new KnowledgeStore(repository, store, 'wiki-v2')` 共用一个快照校验边界；不增加用户设置或 CLI 参数。普通构造仍仅接受 v1，编辑器与随包独立 MCP 保持默认行为。格式 2 按文章模型严格校验，拒绝 trim 等值归一化，避免卡片操作顺带修改人工说明。

原单卡发布/回退、新卡片创建/移除、草稿/三方合并和 prepared 标记恢复改用同一边界读取/写入完整快照，文章整体保留。原始备份字节继续保留，卡片回退仍递增修订。卡片变化后文章引用不自动重绑，变更提示仍有效。历史记录的版本与知识格式版本独立，旧 journal 1/2 的完整快照等价检查同样覆盖文章，不能夹带删除文章或格式切换。

## 路径核对

| 路径                                  | 本轮结果 / 边界                                                                           |
| ------------------------------------- | ----------------------------------------------------------------------------------------- |
| Store status/search/read/propose      | 显式 v2 兼容；默认拒绝 v2，不迁移                                                         |
| Publication 全快照与 history/recovery | 统一校验，保留文章；重算 hash 也不能掩盖额外文章/格式修改                                 |
| Draft / 三方 merge                    | 已有基础校验及人工保留规则沿用；v2 完整文章值不变                                         |
| Generation / jobs / creation removal  | full base digest 包括文章；自编 producer 找回不调用真实模型，不重新生成                   |
| Incremental / recover                 | 用确定性 response seam 验证候选/发布/找回；不冒充真实模型                                 |
| Impact / scan                         | 卡片依赖仍为元数据基线；v2 快照下相同完整基础保护有效，不宣称文章影响图已实现             |
| Wiki reader                           | 同一 v2 正式卡片投影可核验；变化引用不替换为新版或静默重绑                                |
| MCP factory                           | 显式 v2 store 下实际协议四工具和卡片发布后重新读取；不等于默认 STDIO/官方 Codex 已接入 v2 |
| Editor / shipped CLI / initialization | 本轮保持 v1；随包 CLI 实测拒绝 v2 且原字节不变，无新设置/命令                             |

七组自编核心测试覆盖默认拒绝、未知模式/格式/字段、文章限额与文本保护、raw BOM/CRLF 备份、卡片 r1→r2→r3、文章/人工理由/旧引用保留、job 重复找回及创建/移除、incremental seam/recover、merge、mixed v1/v2 历史及旧基础候选拒绝、prepared 标记恢复、重算哈希的篡改/格式降级拒绝。另有隔离 MCP 工厂协议与随包 CLI 拒绝的集成检查。真实产品迁移尚未实现，测试中的 fixture 格式切换不计作迁移验收。
