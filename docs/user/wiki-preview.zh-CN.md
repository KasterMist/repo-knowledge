# Wiki 文章阅读预览（开发版）

当前阅读器只查看未发布的文章预览，不导入、不迁移或发布知识库；正式存储/MCP 仍为 v1。文章生成与审阅发布还在 T27 后续切片。

## 打开自编演示

1. 在安装了开发包的 Windows 或 Remote SSH 工作区执行 Open Three-Card Demo。
2. 从 Repo Knowledge 主页点击“打开 Wiki 文章预览”，或执行 Open Wiki Preview。
3. 选择演示目录中的 `wiki-preview.json`。多仓库工作区先选择仓库；Remote SSH 请选择远端宿主上的预览文件。
4. 左侧目录有“项目概述”和“缓存模块”。点击切换文章，右侧呈现标题、段落、强调、代码块、列表及表格。
5. 点击文章下方源码证据按钮，在同一执行宿主打开引用文件及行。正文中的链接和图片不执行或加载，HTML 按文本展示。

## 认识状态

- **匹配引用的源码已核验**：本次读取时，当前正式卡片与文章引用匹配，且其源码证据可读取并匹配。不是对全部说明或历史设计动机的证明。
- **源码已变化或不可读取**：保留卡片正文并醒目标记过期/不可用，请复核。证据按钮跳转前再次检查，路径越界、缺失、非法范围不能打开。
- **卡片已变化或缺失**：不悄悄换成新版卡片正文，显示需复核。刷新不会自动重新绑定或重写文章。
- **尚无可核验的源码引用**：例如仅含未引用卡片的说明，不能标成“源码有效”。

说明块区分上下文、推测和人工设计理由记录，同时显示作者标签未经身份认证。文章说明和卡片事实仍须审阅，不因为出现在阅读器中就成为已验证结论。

“重新核验并刷新”是显式只读操作。知识版本变化后，旧页面的证据请求会被拒绝，需刷新；配置或工作区文件夹变化会关闭旧阅读器，避免串仓库。预览文件提供目录/说明，事实正文始终取自所选仓库的正式卡片；即使文件内含其他正文，也不会覆盖正式知识。

本轮有自动化编辑器宿主与安全边界证据，但截图工具失败，尚未完成视觉验收；详见 [T27 记录](../development/t27-wiki.zh-CN.md)。已发布 M1 alpha 不包含此阅读器。
