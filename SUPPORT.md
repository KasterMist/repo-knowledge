# Support

For reproducible bugs and feature requests, use this repository's GitHub Issues after reading the [README](README.md) and [roadmap](docs/product/roadmap.md). Include the commit/version, Windows or Linux version, Node, VS Code and Codex versions, and a sanitized minimal example.

M0 is a development foundation, not a working extension. Do not include credentials or private repositories. For sensitive vulnerabilities, follow [SECURITY](SECURITY.md). Community support has no guaranteed response time.
